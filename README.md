# 🎱 Primeiro Nacional de Sinuca — Drumond Sports

Plataforma web desenvolvida para apoiar a divulgação e a organização digital de um campeonato real de sinuca. O projeto reúne informações do evento, divulgação de ingressos e oportunidades para patrocinadores em uma experiência acessível pela web.

## ✨ Funcionalidades

* **Página principal:** apresentação do evento, contagem regressiva, programação e localização.
* **Ingressos:** exibição de lotes, preços, disponibilidade e links relacionados à compra.
* **Área para patrocinadores:** apresentação das oportunidades de parceria e contato via WhatsApp.
* **Painel administrativo:** gerenciamento de configurações do site, fotos, patrocinadores, lotes de ingressos e programação.
* **Galeria interativa:** envio e organização de imagens.
* **Integrações de comunicação e métricas:** links configuráveis e acompanhamento de interações.

## 🛠️ Tecnologias

* Next.js
* React
* TypeScript
* Tailwind CSS
* Supabase — banco de dados, autenticação e armazenamento de imagens
* Framer Motion — animações
